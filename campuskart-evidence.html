CampusKart

An end-to-end ERP consulting and implementation project involving business process analysis, BPMN modelling and Odoo implementation across core business workflows.

PROJECT OVERVIEW

From process analysis to ERP implementation

The project involved identifying and modelling business processes, designing improved workflows and implementing the proposed solution in Odoo using dummy transactional data. The implementation covered website, sales, inventory, purchasing, delivery and accounting workflows.
